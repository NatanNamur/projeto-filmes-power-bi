# 🎬 Análise Cinematográfica — Power BI

Projeto de Business Intelligence desenvolvido no Power BI, com o objetivo de analisar o desempenho comercial da indústria cinematográfica, explorando orçamento, bilheteria, gêneros, países, catálogo e elenco.

## 📊 Sobre o projeto

O relatório foi desenvolvido como projeto de análise de dados, envolvendo tratamento, transformação, modelagem e visualização de informações.

**Principais indicadores:**
- 137 filmes analisados.
- US$ 298,61 bilhões em bilheteria mundial (conforme a base do projeto).
- US$ 15,98 bilhões em orçamento total.
- 278 associações entre filmes e protagonistas.
- 191 protagonistas distintos.

## 🛠️ Ferramentas utilizadas

- Microsoft Power BI Desktop
- Power Query
- DAX
- Deneb
- API do TMDB para obtenção de imagens dos filmes.

## 📑 Estrutura do relatório

**01. Início**
Visão geral do catálogo e destaques de desempenho.

**02. Bilheteria**
Análise de arrecadação, orçamento e desempenho por gênero.

**03. Catálogo**
Exploração dos filmes e suas informações.

**04. Mercados Globais**
Análise por países, gêneros e regiões.

**05. Elenco & Estrelas**
Análise de protagonistas e suas participações nos filmes.

## 🔎 Desenvolvimento técnico

O projeto envolveu:
- Tratamento e padronização de dados no Power Query.
- Construção de relacionamentos entre tabelas.
- Desenvolvimento de medidas DAX.
- Criação de indicadores e rankings.
- Desenvolvimento de visualizações personalizadas.
- Utilização de bookmarks para navegação entre análises.

## 📌 Observação

A base de dados possui caráter fictício e foi organizada para fins de estudo e demonstração de técnicas de Business Intelligence.
